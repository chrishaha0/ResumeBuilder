# 📝 履歷產生器 (Resume Builder)

一款專為長輩設計的線上履歷編輯工具。無需安裝任何軟體，只需打開網頁即可輕鬆填寫、即時預覽，並支援一鍵匯出為 PDF 或 Word (DOCX) 檔案。

## ✨ 核心特色 (Features)

*   👵 **長輩友善設計 (Senior-Friendly UI)**
    *   **超大字體**：全站基礎字體 20px 以上，標題與按鈕字體放大，保護視力。
    *   **護眼配色**：捨棄刺眼的高飽和色彩，採用沉穩的「深苔蘚綠」、「深暖棕」與「柔和米黃」大地色系。
    *   **防呆大按鈕**：輸入框與勾選框大幅增加留白，適合手機觸控，不易誤觸。
*   📱 **完美支援行動裝置 (Mobile-First RWD)**
    *   手機版專屬的「底部導覽列 (Bottom Nav)」，讓使用者能專注在「編輯」與「預覽」間單純切換。
    *   在平板或電腦螢幕上，則會自動展開為高效的「雙欄並排」模式。
*   👁️ **即時 A4 預覽 (Live A4 Preview)**
    *   右側（或預覽分頁）提供真實 A4 尺寸的預覽畫面，輸入資料即時呈現「所見即所得」。
    *   自動縮放引擎，確保在各種尺寸的手機螢幕上都不會版面錯位。
*   ⚙️ **高度客製化 (Customizable Layout)**
    *   **自訂標題與顯示/隱藏**：每一個區塊的標題皆可自由修改，並提供切換開關，不要的區塊可以選擇隱藏（匯出時也會自動濾除）。
    *   **動態自傳段落**：內建「新增/刪除自傳段落」功能，排版不再受限。
*   💾 **雙格式一鍵匯出 (Export Options)**
    *   **匯出 PDF**：串接 `html2pdf.js`，自動將排版轉為高畫質 PDF，方便直接列印或寄送。
    *   **匯出 DOCX (Word)**：採用原生 JavaScript Blob 技術，轉譯為 Word 可讀取的格式，方便後續進階排版。

## 🚀 快速開始 (How to Use)

本專案為純前端網頁應用程式，無需任何後端伺服器環境。

1. **下載檔案**：將 `resume-builder.html` 下載至您的電腦或手機。
2. **開啟網頁**：使用任何現代瀏覽器（Google Chrome、Safari、Edge 等）點擊兩下開啟該 HTML 檔案。
3. **開始編輯**：
   * 在左側（或手機的「編輯履歷」頁籤）填寫您的個人資料、學歷、經歷等。
   * 點擊區塊右上角的「顯示此區塊」可以控制該段落是否要顯示在最終履歷上。
4. **預覽與下載**：
   * 確認右側（或手機的「預覽與下載」頁籤）的排版結果。
   * 點擊畫面上方的「下載 PDF」或「下載 DOCX」按鈕即可取得履歷檔案。

## 🛠️ 技術架構 (Tech Stack)

*   **核心語言**：HTML5, CSS3, Vanilla JavaScript (ES6+)
*   **樣式框架**：[Tailwind CSS](https://tailwindcss.com/) (透過 CDN 載入)
*   **PDF 輸出引擎**：[html2pdf.js](https://ekoopmans.github.io/html2pdf.js/)
*   **Word 輸出引擎**：HTML to MS Word (使用 MIME type `application/msword` 與 JS Blob)

## 📌 注意事項

*   匯出 PDF 時，系統會自動將比例還原至 100% 進行截圖渲染，以確保畫質清晰。
*   匯出 Word 檔案時，因為是透過 HTML 轉換，建議使用 Microsoft Word 開啟以獲得最佳的相容性。
